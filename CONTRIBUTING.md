## Developer Certificate of Origin

All contributions must comply with the
[Developer Certificate of Origin (DCO), version 1.1](https://developercertificate.org/).
By signing off a contribution, contributors certify that they have the right
to submit it under the applicable open-source license.

Each commit must include a `Signed-off-by` line containing the contributor's
name and email address. Add the sign-off automatically when creating a commit:

```text
git commit --signoff
```

The sign-off certifies the contributor's right to submit the contribution. It
does not transfer copyright ownership.
